# Memories V3 Android build

This branch is a safe staging branch; do not merge until validated.

**Required before building:** upload the validated Memories V3 HTML as `app/src/main/assets/index.html`, replacing the old asset. The validated source is `Memories_V3_Bordeaux_Harmonise_TEST.html` (approximately 22 MB), also available inside the Android project ZIP.

Then go to Actions → Build Memories V3 APK → Run workflow, select `memories-v3-apk`. Download the `Memories-V3-APK` artifact from the successful run.

Do not uninstall the currently installed app before backing up experiences and verifying the new APK.
